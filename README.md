# Homebrew tap for Steerglass

[Steerglass](https://steerglass.com) is a fast, native desktop app to browse, debug and operate many Kubernetes clusters at once.

```sh
brew install --cask davidebettio/tap/steerglass
```

Steerglass updates itself; `brew upgrade` works too. The cask in this repository is updated automatically on every release.

To uninstall: `brew uninstall --cask steerglass` (add `--zap` to also remove its settings).
